# Beyond-the-Enzyme-Latch-meta-analyses
This repository contains code used to perform the meta-analyses in the Beyond the Enzyme-Latch publication in Global Change Biology
Four R notebook files contain the code.
The example_metaanalysis_metacor and example_metaanalysis_metagen files contain the code used to perform the meta-analyses using the two different functions.
The ROB file contains code used to process and generate figures showing the results of the risk of bias assessment for the meta-analyses.
The all_data_representation file contains code used to process and generate figures showing the representativness of the meta-analyses.
